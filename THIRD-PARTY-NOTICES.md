# Third-party notices and source access

The application source is delivered with this project. Third-party components retain their own copyright and license terms. The original application icon is generated by `scripts/make-icon.py`.

| Component | Version / source | License / delivery |
|---|---|---|
| LibVLCSharp | 3.10.2, commit `3082c09ca955131c705fc4767fde03e9c4a14999` | LGPL-2.1-or-later; dynamically loaded managed assembly; exact upstream source ZIP included |
| VideoLAN.LibVLC.Windows | 3.0.24 NuGet package | Package declares LGPL-2.1-or-later; native VLC modules and linked dependencies retain their individual terms; VLC 3.0.24 source tarball, build/contrib recipes and LGPL/GPL texts included |
| .NET / Windows Forms runtime | Runtime selected by .NET SDK 10.0.404 for win-x64 publish | MIT and third-party notices; unmodified Microsoft runtime files, license and notices retained with publish |
| xUnit / VSTest | Versions pinned in test projects and lockfiles | Build/test dependencies, not shipped in the application runtime |

Both libVLC and LibVLCSharp are separate, replaceable libraries. This project imposes no restriction on replacing or debugging modified LGPL components. The complete application source and build scripts are available, and the application is not trimmed or bundled into an opaque single executable. Original third-party source notices are preserved in their archives.

Included source archives:

- `third_party/sources/vlc-3.0.24.tar.xz` from [VideoLAN's 3.0.24 release](https://download.videolan.org/pub/videolan/vlc/3.0.24/). SHA-256: `e7cab503d1d7d5849b89d2cf0e1ee60d0ef6d012407791b644b9cfc0cc225fdf`, verified against the upstream checksum.
- `third_party/sources/libvlcsharp-3.10.2.zip` from the [exact VideoLAN repository commit](https://github.com/videolan/libvlcsharp/tree/3082c09ca955131c705fc4767fde03e9c4a14999). Downloaded archive SHA-256: `7c7b56d71721e7f3f12607e629aeca9f8416119a24cd4d016cf7f8f1f9940336`.

The VLC archive includes the module source, patches and `contrib/src/*/rules.mak` build recipes for linked libraries. `third_party/contrib-sources.json` preserves 127 upstream dependency source URLs and SHA-512 checksums extracted from that release. Git-based dependencies (including x264) are identified by their pinned commits in the corresponding `rules.mak`. Individual dependency license texts are in those source archives. This manifest is an upstream recipe index, not a claim that every listed dependency is linked into this package. Do not remove original notices when replacing the native runtime. Before wider binary redistribution, reconcile the native vendor build's complete corresponding-source/dependency set with these recipes; that distribution audit has not been completed in this engineering build.

Runtime support, patent/codec availability and third-party licenses are separate concerns; no universal codec availability or redistribution clearance is asserted.
