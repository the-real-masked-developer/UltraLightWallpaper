# Démarrage sur un autre PC

UltraLightWallpaper 1.1 — Utilisation sur un autre PC

Compatible : Windows 11, processeur x64 (Intel ou AMD).
Le programme inclut .NET, VLC et ses plug-ins. Aucune installation séparée de .NET ou VLC n’est nécessaire.

1. Copiez le ZIP sur l’autre ordinateur (clé USB, disque externe ou transfert de fichier).
2. Faites « Extraire tout ». Choisissez un chemin court, par exemple C:\Apps\UltraLightWallpaper.
3. Ouvrez le dossier extrait, puis lancez UltraLightWallpaper.exe.
4. Dans Fonds d’écran, choisissez un écran puis « Choisir une vidéo… ».
5. Répétez pour chaque écran. Réglez le cadrage, la vitesse et les points de début et de fin si besoin.

Copiez séparément les vidéos que vous souhaitez utiliser. Elles ne sont pas incluses dans ce ZIP.
Sur le nouveau PC, sélectionnez leur nouvel emplacement : les identifiants d’écrans et les chemins de l’ancien ordinateur ne sont pas réutilisés.

Gardez tout le dossier extrait : ne copiez pas uniquement le fichier EXE.
Fermer la fenêtre laisse les fonds d’écran actifs. Pour arrêter complètement le logiciel, utilisez Application → Quitter l’application ou son icône près de l’horloge.
Pour un démarrage automatique, activez Application → Démarrer avec Windows sur ce PC.

Les réglages sont enregistrés par utilisateur dans %LOCALAPPDATA%\UltraLightWallpaper.
Cette version est autonome, mais elle ne conserve pas ses réglages sur la clé USB.

Le programme n’est pas signé. Si la politique de sécurité du PC le refuse, utilisez une procédure de déploiement approuvée ; ne désactivez pas les protections Windows.
